# AI Mystery Room 🔎

AI Mystery Room is a detective game where players find clues, investigate suspects, and solve a mystery. It is built using HTML, CSS, JavaScript, Python, Flask, and MySQL.

## Features
- Choose a difficulty level.
- Explore clues.
- Investigate suspects.
- Find the culprit and earn points.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL
